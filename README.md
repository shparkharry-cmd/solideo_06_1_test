# 🖥️ 시스템 리소스 실시간 모니터링 프로그램

Python 기반의 실시간 시스템 리소스 모니터링 프로그램입니다. 웹 대시보드를 통해 실시간으로 시스템 상태를 모니터링하고, 자동으로 PDF 리포트를 생성합니다.

## ✨ 주요 기능

### 📊 모니터링 대상
- **CPU**: 사용률(%), 코어별 사용률, 온도(°C)
- **GPU**: 사용률(%), 메모리, 온도(°C) - GPU가 있는 경우
- **메모리(RAM)**: 총 용량, 사용량, 사용률(%)
- **디스크**: 각 드라이브별 용량, 사용량, 읽기/쓰기 속도(MB/s)
- **네트워크**: 업로드/다운로드 속도(MB/s), 총 데이터량
- **프로세스**: CPU/메모리 사용 상위 5개 프로세스

### 🎯 실시간 데이터 수집
- 1초 간격으로 데이터 수집
- 5분(300초) 동안 자동 수집
- 타임스탬프와 함께 모든 데이터 저장

### 📈 웹 대시보드
- **게이지 차트**: CPU, GPU, 메모리, 디스크 사용률을 시각적으로 표시
- **라인 그래프**: 시간별 CPU, 메모리, 네트워크 추이 실시간 표시
- **바 차트**: 프로세스별 리소스 사용량
- **색상 코딩**:
  - 🟢 녹색 (0-60%): 정상
  - 🟡 노란색 (60-80%): 주의
  - 🔴 빨간색 (80-100%): 위험

### 📄 PDF 리포트 자동 생성
5분 모니터링 완료 후 자동으로 생성됩니다:
- **표지**: 모니터링 기간, 시스템 정보, 생성 시간
- **요약표**: 각 리소스의 평균, 최소, 최대값
- **그래프**: CPU, 메모리, 네트워크, 온도 추이 그래프
- **프로세스 목록**: 상위 프로세스 리스트
- **분석 및 권장사항**: 병목 구간 분석 및 최적화 제안

## 🚀 설치 및 실행

### 1. 필수 요구사항
- Python 3.8 이상
- pip (Python 패키지 관리자)
- 웹 브라우저 (Chrome, Firefox, Edge 등)

### 2. 의존성 설치

```bash
pip install -r requirements.txt
```

또는 개별 설치:

```bash
pip install psutil websockets reportlab matplotlib GPUtil
```

**주의**: `GPUtil`은 NVIDIA GPU가 있는 경우에만 필요합니다. GPU가 없다면 설치하지 않아도 프로그램은 정상 작동합니다.

### 3. 프로그램 실행

#### 기본 실행 (5분 모니터링)
```bash
python main.py
```

#### 커스텀 시간 설정
```bash
python main.py 60    # 60초 (1분) 모니터링
python main.py 600   # 600초 (10분) 모니터링
```

### 4. 대시보드 접속

프로그램 실행 시 자동으로 브라우저가 열립니다. 자동으로 열리지 않는 경우:

```
http://localhost:8000
```

위 주소를 브라우저에서 직접 입력하세요.

## 📊 대시보드 화면 구성

### 상단
- **타이머**: 현재 경과 시간 / 전체 시간
- **연결 상태**: WebSocket 연결 상태
- **샘플 수**: 수집된 데이터 샘플 개수

### 게이지 영역
- CPU, 메모리, GPU(있는 경우), 디스크 사용률을 게이지로 표시
- 색상으로 상태 구분 (녹색/노란색/빨간색)

### 그래프 영역
- **CPU 사용률 추이**: 시간에 따른 CPU 사용률 변화
- **메모리 사용률 추이**: 시간에 따른 메모리 사용률 변화
- **네트워크 속도**: 업로드/다운로드 속도 실시간 표시
- **온도 추이**: CPU 온도 변화 (온도 센서가 있는 경우)

### 프로세스 테이블
- CPU 사용 상위 5개 프로세스
- 메모리 사용 상위 5개 프로세스

## 📄 PDF 리포트

### 저장 위치
```
reports/system_monitor_report_YYYYMMDD_HHMMSS.pdf
```

예: `reports/system_monitor_report_20250106_143025.pdf`

### 리포트 내용
1. **표지 페이지**
   - 모니터링 기간
   - 시스템 정보
   - 리포트 생성 시간

2. **시스템 정보**
   - 운영체제, 프로세서, 메모리 등

3. **요약 통계**
   - CPU, 메모리, 네트워크의 평균/최소/최대값

4. **그래프**
   - CPU 사용률 추이
   - 메모리 사용률 추이
   - 네트워크 속도 추이
   - 온도 추이 (해당되는 경우)

5. **프로세스 테이블**
   - 최종 측정 시점의 상위 프로세스

6. **분석 및 권장사항**
   - 리소스 사용 패턴 분석
   - 최적화 제안

## 🔧 기술 스택

### Backend
- **Python 3.8+**
- **psutil**: 시스템 정보 수집
- **GPUtil**: GPU 모니터링
- **websockets**: 실시간 통신
- **reportlab**: PDF 생성
- **matplotlib**: 그래프 생성

### Frontend
- **HTML5/CSS3**: 웹 인터페이스
- **JavaScript (ES6+)**: 동적 업데이트
- **Chart.js**: 차트 라이브러리
- **WebSocket API**: 실시간 데이터 수신

## ⚠️ 주의사항

### 권한
- Linux/macOS: 일부 시스템 정보를 읽기 위해 `sudo` 권한이 필요할 수 있습니다.
- Windows: 관리자 권한으로 실행하면 더 많은 정보를 수집할 수 있습니다.

### GPU 모니터링
- NVIDIA GPU만 지원됩니다 (GPUtil 라이브러리 사용)
- GPU가 없거나 지원되지 않는 경우 GPU 정보는 표시되지 않습니다.

### 온도 센서
- 온도 정보는 시스템에 센서가 있는 경우에만 표시됩니다.
- Linux에서는 `lm-sensors` 패키지가 설치되어 있어야 할 수 있습니다.

### 포트 사용
- HTTP: 8000
- WebSocket: 8765
- 이 포트들이 이미 사용 중이면 프로그램이 실행되지 않습니다.

## 🐛 문제 해결

### 브라우저가 자동으로 열리지 않음
→ 수동으로 `http://localhost:8000` 접속

### "연결 끊김" 표시
→ 백엔드 서버가 실행 중인지 확인
→ 포트 8765가 열려있는지 확인

### GPU 정보가 표시되지 않음
→ NVIDIA GPU가 설치되어 있는지 확인
→ `nvidia-smi` 명령어가 작동하는지 확인

### 온도 정보가 표시되지 않음
→ 시스템에 온도 센서가 없을 수 있습니다 (정상)
→ Linux: `sudo sensors-detect` 실행

### PDF 생성 실패
→ `reports/` 폴더에 쓰기 권한이 있는지 확인
→ 필요한 라이브러리가 모두 설치되어 있는지 확인
